## 🚀 READY FOR PRODUCTION

### **Installation**
```bash
# Clone repository
git clone <repo-url>
cd BigDataSatelliteSurveillanceTerrain

# Install dependencies
pip install -r requirements.txt

# Install package
pip install -e .
```

### **Quick Start**
```bash
# Run examples
python examples/quickstart.py

# Train a model
python main.py train --architecture swin --data ./data --epochs 50

# Run inference
python main.py predict --model ./model.h5 --input ./satellite_image.tif

# Start API server
python main.py serve --port 8000

# Get help
python main.py --help
```
