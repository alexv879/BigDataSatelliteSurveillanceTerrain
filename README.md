## 🎓 **Quick Start**

### **1. Installation**
```bash
# Clone repository
git clone <repo-url>
cd BigDataSatelliteSurveillanceTerrain

# Install dependencies
pip install -r requirements.txt
```

### **2. Train Models**
```bash
# Swin Transformer (best accuracy)
python train_modern.py model.architecture=swin model.variant=small

# Vision Transformer
python train_modern.py model.architecture=vit

# EfficientNetV2
python train_modern.py model.architecture=efficientnetv2 model.variant=B2

# With hyperparameter tuning
python -m optimization.hyperparameter_tuning --model-type swin --n-trials 50

# Distributed training (8 GPUs)
python train_modern.py hardware.distributed.enabled=true
```

### **3. Neural Architecture Search**
```bash
# Random search
python -m nas.neural_architecture_search --method random --trials 100

# Evolutionary search
python -m nas.neural_architecture_search --method evolutionary --generations 50
```

### **4. Few-Shot Learning**
```bash
# Train prototypical network
python -m fewshot.prototypical_networks --n-way 5 --k-shot 5
```

### **5. Create Ensemble**
```bash
# Stacking ensemble (best accuracy)
python -m ensemble.model_ensemble --type stacking

# Weighted ensemble
python -m ensemble.model_ensemble --type weighted
```

### **6. Production Deployment**
```bash
# Docker Compose (development)
docker-compose up -d

# Kubernetes (production)
kubectl apply -f k8s/deployment.yaml

# Access services:
# - API: http://localhost:8000
# - Docs: http://localhost:8000/docs
# - MLflow: http://localhost:5000
# - Grafana: http://localhost:3000
```

### **7. Run Benchmarks**
```bash
# Comprehensive benchmarking
python -m benchmarks.performance_suite
```
